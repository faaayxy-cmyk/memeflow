# MEMIX

Crypto Meme Tracker with AI-powered analysis.

## Features
- 📊 Real-time meme coin tracking
- 🤖 AI advisor powered by Groq
- 📈 Interactive charts
- 🔍 Search and filters

## Tech Stack
- Vanilla JavaScript
- Express.js backend
- Groq AI API
- CoinGecko API

## Deploy
- Frontend & Backend: Vercel
